# Astro Health Monitor — live demo build

This repository only hosts the **built static demo** (no source) for the NASA Space Apps Challenge 2026 project "Astro Health Monitor".

- Live demo: https://shyfox-01.github.io/astro-health-monitor/
- Everything runs in the browser: simulation, monitoring, self-checks, response steps and device programs.
- Simulation prototype. Crew, symptoms and faults are simulated or scripted; radiation curves are real NASA data (Curiosity MSL-RAD, Artemis I / Orion HERA) and the cabin CO₂ history is ISS EDA telemetry. Not a medical device and not clinically validated; decision support, not diagnosis.
- Crew 3D avatars: Microsoft Rocketbox (MIT). Data courtesy of NASA OSDR (EDA, RadLab) and the MSL mission. Not affiliated with or endorsed by NASA.
